# Hay una carta para ti

Una aplicación web interactiva para crear tarjetas personalizadas con nombre, mensaje, imagen y fondo temático. Los datos se guardan automáticamente en el navegador usando localStorage, lo que permite que la tarjeta persista entre sesiones.

## 📦 Características

- 📝 Formulario con campos para nombre, email, fecha, mensaje, remitente e imagen.

- 🎨 Vista previa en tiempo real con fondo temático (cumpleaños, Navidad, San Valentín).

- 💾 Persistencia automática con localStorage.

- 🔄 Botón de reseteo que limpia los campos y restaura valores por defecto.

- 📁 Carga de imagen personalizada con almacenamiento en base64.

## 🚀 Cómo usar

- Abrir el proyecto en el navegador.

- Completar los campos del formulario.

- Seleccionar un fondo temático desde el desplegable.

- Subir una imagen si se desea.

- Ver la tarjeta generada en tiempo real.

- Cerrar y volver más tarde: los datos se guardan automáticamente.

- Usar el botón “Resetear” para volver a los valores iniciales.

## 🧠 Tecnologías utilizadas

- HTML5 (partials)

- SCSS

- JavaScript

- localStorage
